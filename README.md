## [@rzkytmgr](https://rzkytmgr.github.io/)

A personal website and portfolio built with [Astro](https://astro.build/). a space for documenting engineering knowledge, sharing technical insights, showcasing selected projects, and exploring ideas through experiments and hands-on implementations.

The site features long-form technical articles, project documentation, curated references, and experimental work across software engineering and related fields. Built with [Astro](https://astro.build/), [TypeScript](https://www.typescriptlang.org/), [Tailwind](https://tailwindcss.com/), and [MDX](https://mdxjs.com/), it includes syntax highlighting powered by [Shiki](https://shiki.style/), GitHub-style alerts, interactive code blocks with copy buttons, article navigation, dark/light themes, and built-in SEO support.

Designed with a focus on readability, maintainability, and performance, the project uses static site generation to deliver a fast and lightweight browsing experience. Development is supported by automated quality checks, including linting, type checking, tests, Git hooks, and a GitHub Actions CI pipeline.
